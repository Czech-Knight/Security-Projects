# Demo Script for Interview / Employer

Use this 60-90 second explanation:

"I built Client360 to simulate the workflow of a junior IT solutions and cyber security engineer in an MSP-style environment. The tool imports Microsoft 365, cloud, firewall, network and backup configuration data, checks for common risks, and produces a client-ready report. It does not just show technical issues; every finding includes evidence, business impact and a recommended fix. I also included optional collector modules for Microsoft Graph, Azure CLI and AWS boto3 so the sample-data version can later be connected to real authorised environments."

Suggested demo flow:

1. Open the dashboard.
2. Show the overall score and severity summary.
3. Open Microsoft 365 tab and show MFA/stale account checks.
4. Open Cloud tab and show public RDP/SSH checks.
5. Open Firewall tab and show any-to-any/admin exposure checks.
6. Open Backup/DR tab and show failed/stale backup checks.
7. Generate the client-ready report.
