# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Expected behaviour

Be constructive, evidence-led, patient with learners, respectful of privacy, and careful with security disclosures. Give technical criticism without personal attacks. Do not publish credentials, private data, weaponised exploit details for real targets, or material that violates another person's authorisation boundary.

## Unacceptable behaviour

Harassment, intimidation, discriminatory language, doxxing, deliberate disclosure of secrets, abuse of project infrastructure, or encouraging unauthorised access is not accepted.

## Enforcement

Project maintainers may remove content or participation that violates these expectations. Security-sensitive concerns should be reported privately rather than debated in a public issue.
