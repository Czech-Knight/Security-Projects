# Project Summary

InfraScope is a defensive MSP-style network audit tool.

It accepts Nmap XML output, builds an asset inventory, identifies risky open services, assigns severity levels, calculates a client risk score, and generates a client-ready HTML report and Mermaid network diagram.

The project is designed to connect directly with security risk assessment automation experience using Python and Nmap, while also matching IT solutions/MSP work such as troubleshooting, documentation, firewall exposure review, and client reporting.
