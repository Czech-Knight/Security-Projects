# Security policy

Report vulnerabilities privately using GitHub's **Report a vulnerability** feature, if enabled for this repository. Do not disclose secrets, production targets, personal scan data or working exploits in public issues. If private reporting is unavailable, contact the maintainers privately to coordinate a safe disclosure.

YashSec Autopilot is a local security-testing workspace. Only assess infrastructure and applications that you own or are explicitly authorized to test. Reports may contain sensitive target details; GitHub Actions artifacts are intended only for non-production test data and sanitized dependency/security findings.

The current development branch is `yash`; archived project components are not guaranteed to receive security updates.
